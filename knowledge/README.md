# knowledge/ — futuras bases de conhecimento globais

Lugar para **referências e conhecimento** que você quer disponíveis em todos os
projetos (sem duplicar em cada repo).

**Convenção (planejada):** documentos markdown organizados por tópico em
`knowledge/<topico>/`. Skills em `skills/` podem referenciar esses arquivos.
Nada específico de um projeto — isso fica no projeto (ex.: `docs/`, `PRD/`).

> Ainda vazio — a organização será definida aqui quando o primeiro conteúdo entrar.
